# 도형의 닮음 — 중2 수업용 웹앱

이송원 제작. 교사 화면을 태블릿/TV로 미러링해 전체 수업에 쓰는 정적 웹앱입니다.

| | 화면 | 내용 |
|---|---|---|
| 1 | 닮음이란? | 작은 도형을 큰 도형에 포개고 늘려 확인 |
| 2 | 닮음 찾기 | 도형 안에서 닮은 두 삼각형 찾아 포개 보기 |
| 3 | 닮음비 | 대응변 : 대응변 — 정의와 문제 |
| 4 | 헷갈리지 않기 | 변의 비가 같아도 닮음이 아닌 경우 |
| 5 | 입체의 닮음 | 가려진 면의 모양 알아맞히기 |
| 6 | 넓이비 | 닮음비 a:b → 넓이비 a²:b² |
| 7 | 부피비 | 닮음비 a:b → 부피비 a³:b³ |
| 8 | 짝맞추기 게임 | 카드 18장, 기록 측정 |
| 9 | 닮은 삼각형 찾기 | 삼각형 9개를 포개 보며 닮음 조건(SSS·SAS·AA) 도입 |

빌드 과정이 없는 정적 사이트입니다. `index.html`이 목록 화면이고 `s1~s9.html`이 각 수업 화면입니다.
